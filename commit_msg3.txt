Sync tray "Show / Hide Bar" checkmark with bar visibility

MainWindow.xaml.cs only.

  * ToolStripMenuItem.Checked is the native WinForms checkmark on a
    ContextMenuStrip item -- zero allocation, no P/Invoke, no menu
    rebuild. We mutate the property in two places only:
      1. InitializeTrayIcon sets it to !_settings.Window.IsHiddenByUser
         so it matches the persisted "user elected to hide" state at
         the very first right-click on the tray.
      2. ToggleVisibility sets it after each flip so the checkmark
         stays in lockstep with the bar, regardless of which path
         drove the toggle (global hotkey vs tray click).
  * Single source of truth: _settings.Window.IsHiddenByUser. Both the
    MainWindow_Loaded Visibility-from-setting path and the tray's
    Checked-mirror path read the same field, so the tray and the bar
    always agree.
  * New cached field _toggleTrayMenuItem keeps the reference so the
    sync point in ToggleVisibility can mutate the same menu item the
    user clicked -- no Items.OfType<>() lookup per toggle.
  * Defensive null check on _toggleTrayMenuItem keeps ToggleVisibility
    safe if called before the tray finishes initializing (e.g., from
    the global hotkey firing during very early startup).

Validation: 0 build errors (only the 2 pre-existing CS8600 nullable
warnings in SettingsWindow.xaml.cs), 39/39 unit tests pass.
