## Usage Example

```csharp
using LibreHardwareMonitor.Hardware;

// Create and configure
var computer = new Computer
{
    IsCpuEnabled = true,
    IsGpuEnabled = true,
    IsMemoryEnabled = true,
    IsMotherboardEnabled = true,
    IsStorageEnabled = true
};

// Start monitoring
computer.Open();

// Iterate hardware
foreach (IHardware hardware in computer.Hardware)
{
    hardware.Update();  // Refresh readings
    
    Console.WriteLine($"{hardware.Name} ({hardware.HardwareType})");
    
    foreach (ISensor sensor in hardware.Sensors)
    {
        Console.WriteLine($"  {sensor.Name}: {sensor.Value} ({sensor.SensorType})");
    }
    
    // Check sub-hardware (e.g., SuperIO under Motherboard)
    foreach (IHardware sub in hardware.SubHardware)
    {
        sub.Update();
        foreach (ISensor sensor in sub.Sensors)
        {
            Console.WriteLine($"    {sensor.Name}: {sensor.Value}");
        }
    }
}

// Cleanup
computer.Close();
```

---

## Important Notes

1. **Administrator Required** - Most hardware access requires elevated privileges
2. **Call Update()** - Sensor values only refresh when `Update()` is called on hardware
3. **SubHardware** - Motherboard sensors are typically under SuperIO child hardware
4. **Thread Safety** - Library is not thread-safe; use locks for multi-threaded access
5. **Dispose Pattern** - Always call `Close()` when done to release resources
